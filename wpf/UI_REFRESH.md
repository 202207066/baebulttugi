# 새 디자인과 빈 식단 배포

최신 실행 파일은 `배불뚝이_새디자인/wpf.exe`입니다. 이전 `배불뚝이_피드백반영` 폴더의 실행 파일은 이전 디자인입니다. 새 폴더 전체를 함께 보관하고 실행해 주세요.

## 화면 변경

- 달력: 큰 초록색 배너와 영어 날짜를 없앴습니다. 한글 연·월, 월요일부터 시작하는 요일, 둥근 날짜 버튼으로 바꿨습니다. 이전/다음 달 및 연·월 선택 기능을 유지했습니다.
- 식단 만들기: 제공 일정, 한 끼 영양 목표, 꼭 포함할 메뉴를 카드로 나눴습니다. 입력창과 요일·끼니 선택을 둥글게 정리하고 초록색 계열로 통일했습니다. 긴 계산 설명은 펼쳐 볼 수 있게 했습니다.

## 배포 메뉴 정책

- **새 사용자에게는 미리 작성된 식단을 넣지 않습니다.** 새 개인 시트 복사 시 `메뉴`와 `식단저장`의 제목 행은 남기고 아래 내용을 비웁니다.
- 트랙A·B의 메뉴 후보 목록은 유지합니다. 식단 만들기에서 사용자가 설정한 결과를 개인 `메뉴` 시트에 저장하는 기능도 유지합니다.
- 이미 구버전으로 복사한 개인 시트는 새 버전에 로그인할 때 예시 행을 확인합니다. `K001 / Day 1` 형태이며 **처음 아홉 칸이 원본 예시와 같고 추가 입력도 없는 행만** 비웁니다.
- 실제 날짜가 입력된 식단, 사용자가 음식 이름을 수정한 행, 메모 등 추가 입력이 있는 행은 보존합니다. 원본 메뉴 시트 자체는 삭제하지 않습니다.
- 이 정리는 새 버전의 개인 시트 준비 단계에서 수행됩니다. 구버전 앱을 계속 열어 두면 기존 예시가 그대로 보일 수 있습니다.

## 검증

- 빌드 성공. 56개 로컬 검증 통과.
- 달력 앞/뒤 월 이동과 월 선택 전환, 한글·월요일 시작 설정 확인.
- 정확히 복사된 예시만 정리하고 사용자 작성·수정 행을 보존하는 조건 확인.
- 두 화면을 WPF로 렌더링해 배치 확인.
- 앞선 실제 앱 테스트에서 구글 계정 연결 후 대시보드와 트랙A 1,314개 조회를 확인했습니다.
- 별도 자동 테스트 프로세스의 실제 Google 저장 검증은 Windows SSL 인증서 접근 오류로 완료하지 못했습니다. 이 과정에서 테스트 시트는 생성되지 않았습니다. 새 예시 정리 로직의 실제 Google 적용은 새 버전 로그인 후 확인해야 합니다.
- 메뉴별 영양정보 미등록 문제는 별도입니다. 현재 실제 영양 수치를 채워야 목표 영양소에 맞춘 자동 조합이 가능합니다.
